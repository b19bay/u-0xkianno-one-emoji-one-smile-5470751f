One emoji, chosen to make a stranger smile: 🫂 — people hugging (U+1FAC2), a single code point and a single grapheme cluster, 4 bytes in UTF-8. The judge in this bounty weighs warmth in order: an emoji that plainly aims to warm a stranger beats one that merely looks happy; warmth at first glance with no context needed; the same reading for any age or background; chosen rather than the default first smiley; and right coming from a stranger, with no intimacy or flirtation. An embrace between two figures is the most literal act of warming someone an emoji can show, it reads instantly everywhere, it is nobody's default smiley, and the hug is between the two figures — a scene of mutual support, not an advance aimed at the reader. The program holds the emoji as a constant, checks the gate (1 to 8 characters, not only white space, exactly one grapheme cluster), writes it alone to entry.txt with no trailing newline, then reads the file back and refuses to finish if it is not byte-identical.
